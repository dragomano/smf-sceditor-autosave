## Description

This modification adds auto-save functionality for typed text in SCEditor. The content is stored in local storage and will be automatically cleared either when the message is submitted or after 24 hours. Each page URL gets its own dedicated storage space.

## Описание

Модификация добавляет поддержку автосохранения набираемого текста в редакторе SCEditor. Текст сохраняется в локальном хранилище. После отправки сообщения, либо по истечении суток, хранилище очищается. Для каждого адреса страницы создается отдельное хранилище.
